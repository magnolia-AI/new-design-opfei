# Vy Design Template

Lightweight design project template for [Vy](https://vy.dev).

This template provides the minimal scaffolding for a design project:

- `design.json` — The design document (artboards, components, variables)
- `globals.css` — Tailwind CSS + shadcn/ui theme tokens (overwritten when a brand is attached)

No `package.json`, no framework config — design projects run entirely in the browser.
